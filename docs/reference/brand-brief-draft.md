# EchoVocis Brand & Product Brief

## 1. Overview

**Brand name:** EchoVocis  
**Agent name:** Emma  
**Product type:** AI-powered voice companion for language fluency  
**Primary experience:** A voice-first app that helps users speak foreign languages more fluently through correction, translation, memory, and personalized practice.

EchoVocis is designed to feel like a smart, supportive speaking coach that users can talk to every day.  
Emma is the voice and personality of the experience: calm, encouraging, intelligent, and practical.

---

## 2. Brand Idea

EchoVocis helps people improve spoken fluency in foreign languages through real conversation.

The core idea is simple:

- when the user speaks in the target language, Emma repeats the sentence in a corrected and more natural way
- when the user speaks in their native language, Emma translates it into the target language
- Emma remembers the user’s speaking history, recurring mistakes, progress, and level over time
- Emma can generate personalized speaking drills, fluency exercises, and level-based reinforcement tests on demand

EchoVocis turns daily speech into continuous language improvement.

---

## 3. Vision

To become the most natural voice companion for building real spoken fluency in any foreign language.

---

## 4. Mission

To make language speaking practice immediate, personalized, and consistent by giving every user a voice coach they can speak with anytime.

---

## 5. Brand Positioning

**EchoVocis** is a voice-first AI language coaching app for people who want to improve spoken fluency through natural interaction, not passive study.

Unlike traditional language apps focused mainly on vocabulary, grammar drills, or static lessons, EchoVocis focuses on **live spoken output**, **correction**, **memory**, and **adaptive coaching**.

## 7. Core Product Promise

**Speak. Improve. Repeat.**

EchoVocis helps users:
- say things in the target language

- practice with exercises generated from their own speaking history

---

## 8. Key Features

### A. Default speaking behavior
1. **If the user speaks in the target language**
   - Emma listens
   - identifies mistakes or awkward phrasing
   - replies with a corrected and more natural version
   - optionally explains the correction simply

2. **If the user speaks in the native language**
   - Emma translates the sentence into the target language
   - optionally offers a more natural spoken version
   - encourages repetition aloud

### B. Mode switching
The user can change the interaction mode through simple commands.

Example modes:
- **Correction mode**
- **Translation mode**
- **Conversation mode**
- **Pronunciation mode**
- **Test mode**
- **Stand-up / meeting practice mode**
- **Roleplay mode**

### C. Long-term memory
EchoVocis stores and organizes:
- spoken sentences
- corrected versions
- recurring grammar mistakes
- vocabulary gaps
- pronunciation-related patterns
- fluency issues
- user goals
- historical progress

### D. Level estimation
Emma can estimate the user’s current language level on request, using stored history and recent performance.

Possible output:
- CEFR-style estimate
- strengths
- weaknesses
- priority areas to improve next

### E. Personalized exercise generation
Emma can generate:
- mini speaking drills
- repetition exercises
- translation prompts
- fluency boosters
- pronunciation practice
- roleplay tasks
- level-based reinforcement tests

All exercises should be generated based on the user’s stored history and current level.
